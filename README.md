# 瘸俠傳：糖門再起

一款以《羅正男的一生》敘事素材為底、融合糖門惡搞武俠與網頁放置 RPG 養成節奏的單機遊戲。

這次不是一路按「下一章」。玩家要在有限行動中自行安排修行、打怪、任務、開台、商城整備與休息；每名 Boss 都有不可用運氣跳過的特殊素質門檻，準備好之後再自行決定何時踢館。

## 核心玩法

- 單角色四維養成：力道、身法、根骨、心眼。
- 每日行動力與短 CD；升級取得自由配點。
- 可在江湖武學鋪習得招式，戰鬥中依真氣與敵方異象選擇武學；另有低機率隱藏禁招。
- 每次收招後顯示獨立行動結算，逐項列出實際獲得、損失、物品與狀態變化。
- 糖門同門修行：糖之漢五種健身、六道現煎料理，以及五位師兄妹各自不同的互動訓練。
- 糖之漢互動中藏有不事先提示的極稀有特殊事件。
- 五大章、每章四個小回目，共二十回；完成前三回的養成與故事考驗後才可挑戰守關者。
- 六個可探索場域，各自改變修行、收入、危險與事件；斷腿崖失足會按最大氣血百分比受傷，最壞可能直接死亡。
- 回合制讀招戰鬥：紅光防禦、紫光看破、武學破防；野怪會依等級與章節成長，精英小 Boss 與守關 Boss 都藏有需要實戰摸索的特殊機制。
- 每名大 Boss 另需一件關鍵物；第一次缺少道具而戰死後，才會留下可跨世保留的取得線索。
- 三種開局皆有貫穿整局的專屬被動：看破成長、瀕死輸出與每日開台承諾。
- 十七張有前置進度的主線江湖帖，以及日常、商城、消耗品、兵器、護具、法器與關鍵道具。
- 五名守關 Boss：睡魔、綠衣邪僧、金銀雙烏、萬面分身、泰山。
- Boss 後故事抉擇會形成自律、信義、人情、節目、混沌五條道路。
- 固定日數會爆發不可撤退的時限戰；荒廢每日修行與忽略同門關係都會招致懲罰甚至死亡。
- 黑市包含高投報高風險交易、盜版武學洗點與巡捕逮捕；直播則會隨機遇到檢舉、停權、存證信函或爆紅事件。
- 死亡後必須轉生；保留成就與一項永久四維加成。
- 24 種跨世成就與多種結局。
- 實況模式聊天室、聊天室聖旨、數字鍵 1–9 快速選擇。
- `localStorage` 自動存檔，不需要後端；一般重整或關閉分頁不會消失。

### 存檔位置與保留規則

遊戲進度存在目前瀏覽器、目前網站來源的 `localStorage`，不是寫入專案檔案或雲端帳號。進度鍵名為 `jimmidog-sugar-gate-v4`，結局圖鑑鍵名為 `jimmidog-sugar-gate-endings-v4`。

只要仍使用相同瀏覽器及相同網址來源（協定、網域與連接埠都相同），重新整理、關閉分頁或重新啟動瀏覽器後仍可繼續。清除網站資料、使用無痕模式、改用另一個瀏覽器，或由不同連接埠開啟時，會被視為另一份存檔。「重新開始」會刪除本世進度，但保留結局圖鑑。

## 直接遊玩

這是純靜態網站。開啟 `index.html` 即可遊玩；若瀏覽器限制本機資源，可在專案目錄啟動任一靜態伺服器，例如：

```bash
python -m http.server 4173
```

然後開啟 `http://127.0.0.1:4173/`。

## 檔案

- `index.html`：遊戲頁面結構。
- `styles.css`：水墨武俠／直播介面與響應式設計。
- `game.js`：資料、養成、戰鬥、任務、商城、Boss、成就、轉生與結局。
- `羅正男的一生.md`：既有完整敘事聖經與史料／虛構處理準則。
