# 羅正男的一生

作者：**吉米狗**

一款以公開生平與台灣實況迷因文化為原型的單頁敘事人生模擬遊戲。遊戲採深黑、紫色、直播狀態與聊天室分欄構成的實況平台風格；視覺系統與內容均已重新設計。人生模擬玩法概念參考 [YaKyoLife](https://github.com/LeoGGcat/yakyulife)，遊戲內容重構為：

- 1992–2013：北投、未報到的大學與普通工作
- 2014–2015：四十包零傳說、六天傳說、亞洲第一、華義與瑞典亞軍
- 2016–2018：起Q／ahq、薛喜、五十大承諾、LULU 迷因、世紀之推、綠色核心卡、老蟹三千萬與 Nonolive
- 2018–2019：亞運國手、排名事件、HGG 全隊失格、冬季冠軍與臺北世界賽
- 2020–2023：戰場第 17 名、728／772 天平台流放、Gogoro 免費仔與 104.2 萬元
- 2024–2026：叉滴娛樂、Vivi 合作、危險留言、Threads 分身、社宅查核、搬家與 28.5 小時爬梯

## v3.0 遊戲系統

- 32 個主線章節（含序章與最終章），每章依難度提供 3–5 種做法
- 史實模式／「如果當時」架空模式
- 精華剪輯、Local 本傳、究極大中計三種難度
- 牌感、練習、精神、信用、競技誠信、名聲與核心人氣
- 怠惰、承諾債、平台風險與分身污染
- 體力、健康、壓力與章節時間管理
- 米特姨、蟹老闆、薛西與熊班長關係值
- 競技、實況、經營、家庭與混亂五條長期人生路線
- 10 種可解鎖路線能力，會反過來改變成功率、資源與事件結果
- 14 組互動式動態事件；每次出現時由玩家從三種處理方式中選擇
- 資產、能力、關係、體力及路線門檻，未達條件的選項會鎖定並說明原因
- 高風險行動顯示動態成功率，受到能力、健康、壓力、難度及路線能力影響
- 19 種常規、隱藏、危機與開放結局，以及跨局結局圖鑑計數
- 迷因收藏、判定戰績、動態事件統計與完整路線結算
- 每次載入採獨立隨機序列，不提供亂數碼輸入
- 私有狀態、編碼鏡像與雙簽章完整性檢查

## 視覺設計

- 深黑背景、紫色主操作色與直播中紅色狀態
- 桌面版主事件流／右側選擇聊天室雙欄介面
- 行動版底部選擇面板
- 頻道頭像、資料面板、聊天訊息與事件卡皆為重新設計

## 取材原則

本作使用「羅正男」及虛構隊伍、平台、卡牌名稱。公開紀錄、當事人回憶、社群迷因與架空內容會在遊戲中分色標記。未證實的私生活傳聞不會由旁白當成事實；父親、住址與非公眾人物資料不重建、不擴散。
